Funktion

Eigene Discord-Anwendungs-ID

Die meisten Nutzer sollten die voreingestellte Discord-Anwendungs-ID beibehalten. Der eigene Modus ist für Nutzer gedacht, die eigene Discord-App-Grafiken verwenden möchten.

Was die Funktion macht

Damit kannst du die voreingestellte Discord-Anwendungs-ID durch die ID einer eigenen Discord-Entwickleranwendung ersetzen.

Wann sie sinnvoll ist

Verwende diese Option nur, wenn du mit Discord-Entwickleranwendungen vertraut bist und ein eigenes Branding oder eigene Grafiken nutzen möchtest.

Einrichtung

Öffne Settings, stelle den Modus für Discord Client ID auf Custom und füge eine gültige Anwendungs-ID ein. Falls etwas nicht funktioniert, wechsle zurück zu Default.

Was du prüfen solltest

  • Die ID muss gültig sein und aus Ziffern bestehen.
  • Die Grafiken deiner Discord-Anwendung müssen korrekt eingerichtet sein.
  • Buttons und Bilder können sich bei eigenen Apps anders verhalten.

Datenschutzhinweise

Die eigene ID ändert die Discord-Rich-Presence-Anwendung, über die der Status angezeigt wird. Welche Titelmetadaten die App ausliest, bleibt unverändert.
