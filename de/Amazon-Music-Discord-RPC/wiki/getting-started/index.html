Erste Schritte

Amazon Music RPC zeigt die Wiedergabe von Amazon Music unter Windows als Discord Rich Presence im Stil von Spotify an. Für die Einrichtung wird der normale Installer empfohlen.

1. App installieren

Lade AmazonMusicRPC_Setup.exe aus dem neuesten GitHub-Release herunter, führe die Datei aus und wähle aus, ob du Verknüpfungen oder einen automatischen Start möchtest.

Neuestes Release herunterladen

2. Benötigte Apps öffnen

  • Starte die Discord-Desktop-App.
  • Starte Amazon Music für Windows. Für erweiterte Metadaten wird die Version aus dem Microsoft Store empfohlen.
  • Starte Amazon Music RPC über die Desktop-Verknüpfung, das Startmenü oder den Infobereich.

3. Erweiterte Metadaten auswählen

Bei einer neuen Installation wirst du gefragt, ob du erweiterte Amazon-Music-Metadaten aktivieren möchtest. Das wird empfohlen, da Titel, Albumcover, Pausenstatus und Zeitangabe damit am genauesten sind.

Erweiterte Metadaten werden derzeit für die Amazon-Music-Version aus dem Microsoft Store entwickelt und getestet. Wenn bei der Version von der Website oder dem Desktop-Installer ein Fehler mit --remote-debugging-port erscheint, installiere die Version aus dem Microsoft Store oder verwende den Fallback-Modus.

4. Song abspielen

Starte die Wiedergabe in Amazon Music und prüfe dein Discord-Profil. Dort sollten Songtitel, Interpret, Albumcover und ein laufender Timer erscheinen.

5. Optionale Funktionen einstellen

Öffne Settings im Infobereich, um Last.fm, ListenBrainz, die private Sitzung, Stichwortfilter, den automatischen Start, den Benachrichtigungs-Fallback oder eine eigene Discord-Anwendungs-ID einzurichten.
