Amazify-CLI

Das Installationsprogramm fügt Amazify zum benutzerspezifischen PATH hinzu. Wenn du amazify ohne Unterbefehl startest, wird die vollständige Befehlsliste ausgegeben.

amazify run

Startet bei Bedarf den Daemon, öffnet Amazon Music oder bringt das Fenster in den Vordergrund, fügt Amazify ein und gibt die Kontrolle an das Terminal zurück.

amazify run --foreground

Führt den Befehl im aktuellen Terminal aus. Verwende diesen Modus, wenn du sofort Protokolle oder Fehlerdetails benötigst.

amazify daemon start

Startet den dauerhaft laufenden Hintergrund-Daemon, ohne ein sichtbares Terminalfenster zu öffnen.

amazify daemon status

Gibt an, ob der Daemon läuft und erreichbar ist.

amazify daemon stop

Fordert den Daemon zum Beenden auf. Wenn du nur Amazon Music schließt, läuft er weiter.

amazify list-candidates

Listet erkannte Startkandidaten für Amazon Music auf. Das hilft, wenn das Finden oder Verbinden mit der Anwendung fehlschlägt.

amazify shortcuts install

Erstellt die Amazify-Startverknüpfungen für die aktuelle Installation neu.

amazify update check

Sucht auf GitHub nach der neuesten geeigneten stabilen Programmversion, ohne sie zu installieren.

amazify update install

Fragt nach einer Bestätigung, lädt das Installationsprogramm herunter, überprüft es und startet anschließend die normale interaktive Installation.

amazify --version

Gibt die aktuell installierte Amazify-Version aus.

Verhalten des Daemons

amazify run übergibt den Startauftrag an den Daemon und wird beendet. Wenn du dieses Terminal schließt, stoppt das den Daemon nicht. Auch nach dem Schließen von Amazon Music bleibt er für den nächsten Start bereit.

Wann der Vordergrundmodus sinnvoll ist

Verwende amazify run --foreground, wenn eine Verknüpfung scheinbar nichts auslöst, das Einfügen fehlschlägt oder du einen aktuellen Fehlerbericht benötigst. Im normalen Betrieb ist der Befehl mit Daemon schneller und kommt ohne Terminalfenster aus.

Befehl nicht gefunden

Öffne nach der Installation ein neues Terminal, damit es den aktualisierten benutzerspezifischen PATH. Fehlt der Befehl weiterhin, installiere Amazify erneut oder starte amazify.exe aus dem CLI-Ordner unter %LOCALAPPDATA%\Programs\Amazify.
