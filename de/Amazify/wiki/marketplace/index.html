Plugins

Marktplatz

Der integrierte Store installiert Pakete aus dem Katalog, ohne sie mit der Anwendung zu bündeln. Bevor Dateien im Plugin-Ordner landen, prüft er Identität und Dateiintegrität.

Marketplace öffnen

Öffne das Amazify-Menü in Amazon Music und wähle Marketplace. Bei jedem Öffnen wird der Online-Katalog aktualisiert und die Manifestversion im Katalog mit den installierten Versionen verglichen.

Paketstatus

  • Download bedeutet, dass das Paket nicht installiert ist.
  • Enable bedeutet, dass es installiert, aber inaktiv ist.
  • Disable entfernt die aktiven Laufzeitänderungen, ohne die Dateien zu löschen.
  • Update bedeutet, dass die Katalogversion neuer ist als die installierte Manifestversion.
  • Reinstall lädt das aktuell aufgeführte Paket erneut herunter und überprüft es.

Was die Katalogprüfung kontrolliert

Der Katalog im Schema v2 benennt ein Quell-Repository, einen unveränderlichen 40-stelligen Git-Commit, den Plugin-Stammordner, das Manifest, die Vertrauensstufe und jede erwartete Datei. Amazify leitet daraus direkte GitHub-URLs ab und prüft für jede Antwort SHA-256-Prüfsumme und Dateigröße, bevor die Installation vorbereitet wird.

Integrität ist keine Sicherheitsprüfung. Eine übereinstimmende Prüfsumme belegt, dass die heruntergeladenen Bytes dem geprüften Katalogeintrag entsprechen. Das belegt nicht, dass beliebiger JavaScript-Code für dein Konto oder deine Amazon-Music-Sitzung sicher ist.

Standard- und Community-Plugins

Stock bezeichnet eine bestimmte Katalogversion, die vom Amazify-Projekt gepflegt, geprüft und getestet wird. Das ist weder ein formelles Audit noch eine Garantie. Sei bei Community-Plugins vorsichtiger: Prüfe vor der Aktivierung Quellcode, Autor, Berechtigungen, festgelegten Commit und Update-Verlauf.

Heruntergeladene Plugins sind zunächst deaktiviert

Installation und Ausführung sind getrennte Entscheidungen. Amazify lädt ein geprüftes Paket herunter und wartet dann auf die ausdrückliche Aktivierung. So kannst du das Paket prüfen, bevor sein JavaScript im Amazon-Music-Renderer ausgeführt wird.

Aktuelle Standard-Plugins

  • Signal Studio ist ein Theme für die gesamte Oberfläche mit kompakter Navigationsleiste, angepassten Flächen, flexiblen Bereichen und einer schwebenden Wiedergabesteuerung.
  • True Big Mode ersetzt den Big Mode von Amazon Music durch synchronisierte Liedtexte, dynamische Album-Art-Darstellung, Wiedergabesteuerung, Positionssteuerung und eine zentrierte Ansicht ohne Liedtexte.

Plugin-Updates

Eine Update-Schaltfläche erscheint, wenn das aktualisierte Katalogmanifest eine neuere semantische Version als das installierte Plugin enthält. Das Update wird wie eine Neuinstallation vorbereitet und geprüft. Anwendungsupdates laufen unabhängig davon.
