Einrichtung

Erste Schritte

Installiere die gebündelte Windows-App, starte den offiziellen Amazon-Music-Client über Amazify und wähle die gewünschten Plugins aus.

Voraussetzungen

  • Windows 10 oder neuer.
  • Die offizielle Amazon-Music-Desktop-App.
  • Eine Internetverbindung für Installationsprogramm, Katalog und Updates. Für die normale Offline-Nutzung von Amazon Music ist weiterhin Amazon Music zuständig.

1. Installationsprogramm herunterladen

Lade AmazifySetup.exe aus dem neuesten stabilen GitHub-Release herunter. Für die Paketinstallation ist Python nicht erforderlich.

AmazifySetup.exe herunterladen

Nicht signiertes Installationsprogramm: Version 1.0.0 ist nicht mit Authenticode signiert. Daher zeigt Windows SmartScreen möglicherweise eine Warnung vor einer unbekannten App an. Lade die Datei aus dem offiziellen Release herunter und vergleiche bei Bedarf die veröffentlichte SHA-256-Prüfsumme.

2. Integrationsoptionen auswählen

Das Installationsprogramm legt Amazify unter %LOCALAPPDATA%\Programs\Amazify ab, fügt den CLI-Ordner zum benutzerspezifischen PATH hinzu und registriert ein Deinstallationsprogramm.

  • Der Daemon startet standardmäßig bei der Anmeldung und ermöglicht so den schnellsten Start.
  • Die Verknüpfung im Startmenü ist immer verfügbar.
  • Verknüpfungen auf dem Desktop und in der Taskleiste sind optional. Das Anheften an die Taskleiste erfolgt nach Möglichkeit, da Windows dies programmgesteuert ablehnen kann.

3. Amazify-Sitzung starten

Öffne Amazon Music (Amazify) im Startmenü oder führe amazify run aus. Der Daemon startet bei Bedarf, findet oder startet Amazon Music mit einem lokalen DevTools-Endpunkt, prüft das Ziel und fügt die Amazify-Laufzeitumgebung ein.

4. Plugin installieren

  1. Öffne das Amazify-Menü in Amazon Music.
  2. Öffne Marketplace.
  3. Lade Signal Studio oder True Big Mode herunter.
  4. Prüfe Autor, Quellcode, Berechtigungen und Vertrauensstufe.
  5. Aktiviere das Plugin ausdrücklich. Heruntergeladene Plugins sind zunächst deaktiviert.

Marketplace-Anleitung lesen

Laufzeitdaten

  • %APPDATA%\Amazify\plugins enthält installierte Plugins.
  • %APPDATA%\Amazify enthält Konfiguration und Daemon-Status.
  • %APPDATA%\Amazify\logs enthält Laufzeitprotokolle zur Fehlerbehebung.

Amazon Music schließen

Wenn du Amazon Music schließt, wird der Hintergrund-Daemon nicht beendet. Das ist beabsichtigt: Er bleibt für den nächsten Start über eine Verknüpfung oder die CLI bereit. Führe amazify daemon stop aus, wenn du ihn ausdrücklich beenden möchtest.
